Bring a version built and tested in another CEDARS environment into this one ({{ environment }}) without a developer: load the package exported from the version's page there. The import always makes a draft. Nothing a filing is checked against changes until an administrator here publishes it, after the same checks as any draft, including the examples and the impact test on this environment's own filings. An existing value list or data dictionary definition is never changed by an import.
