The CPUC adopts goals by decision about every two years. Each decision is loaded as a set of goals: cumulative goals for each cycle and annual targets, for each IOU. The newest confirmed set replaces the earlier ones for every year it covers; earlier sets stay here for the record. The portfolio dashboard compares forecasts and claims with the goals in force.
