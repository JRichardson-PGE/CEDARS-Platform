Do you need an account?

No, to read: the portfolio dashboard, record downloads, documents, the data dictionary, the validation rules and the filing calendar are open to everyone. You need an account to file for a program administrator (PA), to review filings for the CPUC, to run cost-effectiveness calculations, or to follow documents.

Create an account and sign in

  1. Choose Create an account and give your work email address and a password.
  2. Open the confirmation link CEDARS emails you. If nothing arrives within a few minutes, look in your junk folder.
  3. Sign in. The first time, CEDARS asks you to set up a second factor: an authenticator app (a six-digit code that changes every 30 seconds) or a security key. Every account uses one.
  4. Keep the recovery codes CEDARS shows you somewhere safe. Each lets you sign in once if you lose your phone or key.

Some organizations sign their people in through their own directory instead; their sign-in page says so.

Ask an organization for access

An account starts with no organization. To file or read for a PA, open your account page and choose Ask an organization for access: pick the organization and the permissions you need (for example claims, read and submit) and say why. The organization's own administrators decide. Access to personal information (contacts and sites in claims) also needs a CPUC data steward's approval, and every use of it is recorded.

Grants can expire, and administrators confirm their people's access once a year, so you may be asked to show you still need it.

Acting for an organization

If you belong to more than one organization, the header shows Acting for with a list: choose the organization and then Switch. Everything you file or run is for the organization you are acting for, and the audit trail records it.

Notifications

Notifications in the header lists what needs you: a filing to review, an access request, a due date coming up, a run that finished, and, if you approve filings, each comment a filing organization posts on one. The count beside it is how many are unread. The same notices go by email. On Notification settings you choose which PAs and programs you follow, which events you hear about, and how many days before each due date you are reminded; Follow this program on a program's page adds it to the programs you follow.

API tokens

Your own systems can file and read through the CEDARS API. On your account page, under API tokens, make a token for one organization and the modules it may use; it can do no more than you can. Copy its key when it is shown: it is shown only once. A token stops working when it expires, when you revoke it, or when you leave the organization. The API description lists every endpoint. Calls are rate limited; the Limits page gives the current rates.

Changes, limits and this guide's release

Every change to CEDARS' specifications, validation rules, limits or system is announced in the release notes before it takes effect, and every page shows the changes coming soon. Signed in, choose Send me each release note by email there to be told of each one. The Limits page lists every limit as the site applies it now (upload sizes, files per upload, run and download sizes, API rates), and each upload field says its own. Each user guide, like this one, says the CEDARS release it was revised for, and the footer shows the release the site runs. The frequently asked questions have short answers with worked examples.
