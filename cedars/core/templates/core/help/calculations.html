Starting a run

Under Calculations, New run prices a job on the ReCET engine:

  1. Upload the job as one .zip holding Measure.csv and, optionally, ProgramCost.csv, the way CET takes a job (or run a draft from Edit inputs).
  2. Choose who the run is for: only you, or an organization you belong to (its members can then see it).
  3. Choose the engine release and the ACC (named by year, for example "2024 ACC"). Which ACC applies to my filing? on the page says which ACC a filing or claim year takes. A CET replica prices a job exactly as that CET release did, its errors included, for comparison only.
  4. Choose the options you need (cost-test set, societal tests, emissions, statewide allocation, filing checks, output format and template), then Start the run. Check the inputs only runs the input checks without pricing.

The run is queued; its page shows its progress, then its files and its results.

Results and comparisons

A finished run's Results page sums the outputs by PA, program, sector and year, with the cost-test ratios. From a run's page you can compare it with another finished run you can see: every total side by side with the difference.

Edit inputs

Edit inputs edits a small job's Measure and ProgramCost tables row by row (jobs of up to 500 measures; edit larger ones offline). Each cell is checked by the engine's own rules as you save, and the draft can be run or downloaded as a job zip.

Output templates

Output templates choose which columns, in which order, a run's measure-level file holds. The full results are kept either way.

Impact profiles

The impact profile library holds every hourly profile a measure can name: deemed profiles generated from eTRM load shapes, custom profiles PAs upload, and the DEER and TOU profiles carried over from CEDARS. Each 8,760 spreads one kWh of savings over the year, per climate zone. To add a custom profile, download the template, give one 8,760 per climate zone that adds up to 1, and upload it; profiles are versioned and runs record the version they used.
