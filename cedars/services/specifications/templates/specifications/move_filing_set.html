{% page_help "specifications/move_filing_set" %}

Every filing in the set follows one filing specification version, for every upload, check and correction. A mistake in a version that is in use is fixed by publishing the next version and moving the set to it. Open versions are checked again against the new version (a calculation they had is void, so they are priced again); confirmed versions stay as they are, recorded against the version they were checked with. The filing calendar's subscribers are told, with the reason.
