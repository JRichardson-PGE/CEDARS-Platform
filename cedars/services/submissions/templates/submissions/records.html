Upload a partial correction

A file of only the records that change or are new, in the filing's own format (a .zip of CSV files named after their tables, an Excel workbook with a sheet per table, or one table's CSV file named after it). Records are matched on their key: a record already in this version is changed, any other is added. A column the file leaves out keeps each record's value; a blank cell makes the value blank. To delete records, add a table (a CSV file or sheet) named Delete with a Table column and the key columns of each record to delete. You see what it would change before anything is changed.
