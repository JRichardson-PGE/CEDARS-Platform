You need no account to read published data. You need one to file for a program administrator (PA), review filings for the CPUC, run calculations or follow documents.

First steps

  1. Create an account with your work email, then open the confirmation link CEDARS emails you.
  2. Sign in and set up a second factor (an authenticator app or a security key). Keep your recovery codes somewhere safe.
  3. To file or read for a PA, ask an organization for access. Its administrators decide; access to personal information also needs a CPUC data steward's approval.
  4. If you belong to more than one organization, choose one under Acting for in the header.
