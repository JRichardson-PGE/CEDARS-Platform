Cost-test sets

{% page_help "refdata/cost_tests" %}

A cost-test definition set says which value streams each cost test adds up and how it shares the program costs (ReCET's COST_TESTS.md). Every run is pinned to one. A filing is priced only on a published set: the one its filing setup names, or the one in force for its first program year. An analysis run may also use a draft. A change to a set is a new version, never an edit.
