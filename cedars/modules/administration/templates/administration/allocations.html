Load a factor file

Loaded for {% if request.organisation and request.organisation.manages_allocation %}{{ request.organisation.code }}{% else %}the CPUC{% endif %}. Start from the factor file template (CSV): Year, ProgramID, ProgramName and PercentElectric, then each funding PA's gas and electric factors.{% if example %} The latest confirmed version, {{ example.label }}, can be downloaded from its page as a starting point.{% endif %}

  • PercentElectric, the program's electric share of its budget from 0 to 1, is required on every row.
  • Electric, gas and PercentElectric values may have at most 4 decimal places (trailing zeros do not count, so 0.44400 is fine). A file with a longer value is refused, with each such cell listed. A blank factor counts as 0.
  • Each row's electric factors must add up to exactly 1.0000, and so must its gas factors.
  • A program that is 100% electric (PercentElectric 1) has gas factors equal to its electric factors, and one that is 0% electric has electric factors equal to its gas factors, so its savings in the other fuel are still allocated. Leave the other fuel's factors blank and they are copied; filled in and different, the file is refused.
  • The weighted factors are computed: PercentElectric × electric + (1 − PercentElectric) × gas, rounded to 4 decimal places. When the rounded values do not add up to 1.0000, the PA whose value was closest to rounding the other way moves by 0.0001 first, until they do. A file that still has weighted factor columns is read, and those columns are ignored.
