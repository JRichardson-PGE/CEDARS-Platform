First steps

  1. Open New run and upload one .zip with Measure.csv and, optionally, ProgramCost.csv.
  2. Choose who the run is for, the engine and the ACC (Which ACC applies to my filing? on the page helps).
  3. Choose Start the run, or Check the inputs only. The run's page shows its progress, then its files and results.

Learn more

  • Edit inputs: edit a small job row by row, or add a measure from eTRM.
  • Output templates: choose the columns a run's file holds.
  • Impact profile library: the hourly profiles measures name, and custom uploads.
  • From a finished run's page, compare it with another run.
