First steps

  1. Find a program in the program catalog by name or PrgID, or pick a program year.
  2. Open it to see its attributes, every version, its statewide allocation factors and the studies that evaluate it.
  3. To change it, choose Change on its page. A change starts a new version; the earlier one is kept. A locked attribute needs a CPUC programs approver's decision.
  4. To add a document about it, choose Add a document on its page: the program is filled in for you.

Statewide programs and each PA's ID of them

A statewide program (for example SW_FS) is allocated to each funding PA under the PA's code in front of its PrgID (PGE_SW_FS, SCE_SW_FS). The statewide program is the source of truth for those IDs: they follow its definition, their PAs do not change them, and every one of them shows the statewide program's documents and evaluations. In the catalog, those IDs open the statewide program's page, which lists each PA's ID of it.

The statewide program's lead PA changes it, and the change reaches every ID that follows it on the same day. Each ID keeps its own versions from before it followed, and its own filings and reports.
