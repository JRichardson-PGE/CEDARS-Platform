An output template is a list of measure-level columns, in order. A run given one (New run, Checks and outputs) writes only those columns, in that order, to its measure-level file; the Results tables and the portfolio summary still use every column. The run's settings keep the columns it was given, so changing a template later does not change what a run asked for.
