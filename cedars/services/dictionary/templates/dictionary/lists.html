Value lists

{% page_help "dictionary/lists" %}

The codes a field may hold, such as the sectors or the climate zones, that the validation rules and the input editor check values against. Each list is kept in versions: the version in force on a date is the newest published one effective by then, and until a list has a version here, the list shipped with the calculation engine{% if release %} (ReCET {{ release }}){% endif %} is the one in force. A code is accepted for claim years from its start year to its end year; a retired code keeps its row with an end year, and a code is never deleted.
