First steps

  1. Open New run and upload one .zip with Measure.csv and, optionally, ProgramCost.csv, or ReCET's job workbook (.xlsx) with a Measure sheet and, optionally, a ProgramCost sheet. ReCET's optional input files (run parameters, 8,760 electric profiles, gas monthly profiles) go under Optional input files, in the zip, or as sheets of the workbook; their columns are in ReCET's input fields. The program registry and the allocation version stand in for a job's own program metadata and statewide factors. Templates to download, at the top of New run, has the engine's own template for each file.
  2. Choose who the run is for, the engine and the ACC (Which ACC applies to my filing? on the page helps).
  3. Choose Start the run, or Check the inputs only. The run's page shows its progress, then its files and results.

Learn more

  • Edit inputs: edit a small job row by row, or add a measure from eTRM.
  • Output templates: choose the columns a run's file holds.
  • Impact profile library: the hourly profiles measures name, and custom uploads.
  • From a finished run's page, compare it with another run.
  • ReCET documents: the engine's full reference: input formats, input fields, output fields with every formula, the method and the cost tests.
