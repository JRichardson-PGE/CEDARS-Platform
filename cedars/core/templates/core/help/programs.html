The program catalog

The program catalog lists every program in the registry, closed programs included. Search by name or PrgID, or pick a program year to see the attributes that applied that year. Other filters filters on any other attribute: choose a field, set what to keep, then Apply. The catalog downloads as CSV.

A program's page

Each program's page shows its status, segment, primary sector, implementer and years, then every version of it, its statewide allocation factors in each allocation version, and the EM&V studies that evaluate it. Filings, claims and runs record the program and allocation versions they used.

Changing a program

  • A program's own administrators change most attributes themselves with Change on its page. A change starts a new version on its effective date; the version before it ends the day before and is kept as it was.
  • A change to a locked attribute (for example the segment or whether a program is excluded from cost-effectiveness) is a request that a CPUC programs approver decides. Approving it starts the new version on the date asked for. Requests are listed under program change requests.
