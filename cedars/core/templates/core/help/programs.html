First steps

  1. Find a program in the program catalog by name or PrgID, or pick a program year.
  2. Open it to see its attributes, every version, its statewide allocation factors and the studies that evaluate it.
  3. To change it, choose Change on its page. A change starts a new version; the earlier one is kept. A locked attribute needs a CPUC programs approver's decision.
  4. To add a document about it, choose Add a document on its page: the program is filled in for you.

Adding a program

A PA's administrators add their PA's programs with Add a program in the program catalog; CPUC system administrators add any PA's, and statewide programs. A new program gets its PrgID and a first version from the day it starts. The PrgID starts with its PA's code (a statewide program's with SW_), is kept for good and is never reused. A PA's ID of a statewide program (PGE_SW_FS for SW_FS) follows the statewide program from the start, so its attributes are copied from it.

Correcting a version

A change records something that changed from a date. A correction puts right a value a version held wrongly, such as a typo or a sector an import got wrong, without starting a new version: choose Correct beside the version in its page's Versions table. The version shows when it was corrected and by whom, and the audit trail keeps the values it had. CPUC system administrators and programs approvers correct directly; a program's administrators send a correction as a request for an approver's decision. Correcting a statewide program's version brings each PA's ID that follows it into line. Filings and published results keep the values they were filed with.

How a program is delivered (resource, deemed, custom, upstream, midstream, downstream, audit, direct install and financing) is under Delivery on the change form.

Statewide programs and each PA's ID of them

A statewide program (for example SW_FS) is allocated to each funding PA under the PA's code in front of its PrgID (PGE_SW_FS, SCE_SW_FS). The statewide program is the source of truth for those IDs: they follow its definition, their PAs do not change them, and every one of them shows the statewide program's documents and evaluations. In the catalog, those IDs open the statewide program's page, which lists each PA's ID of it.

The statewide program's lead PA changes it, and the change reaches every ID that follows it on the same day. Each ID keeps its own versions from before it followed, and its own filings and reports.
