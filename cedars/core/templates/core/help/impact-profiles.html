An impact profile spreads one kWh of savings over the hours of the year (an 8,760, one value per hour), per climate zone. A measure names one in its electric impact profile field. The impact profile library has every profile: deemed profiles generated from eTRM load shapes, custom profiles uploaded by program administrators, and the DEER and TOU profiles carried over from CEDARS. Profiles are versioned, and a run or claim keeps the version it was priced with.

A custom profile

  1. Add a custom profile from the template linked beside the form: one 8,760 per climate zone (1 to 16, or System for a statewide profile), each adding up to 1.
  2. The file is checked before the profile is added. It belongs to the organization you act for and everyone signed in can read it.
  3. Its owner replaces it with a new version, or retires it, from its page. A retired profile's versions are kept for the runs and claims that used them.

Deemed load shapes

  • Deemed load shapes lists the draft eTRM measure packages starting on or after the load-shape start date (1 January 2027 unless the CPUC changes it), synced nightly, each with the PA that leads it.
  • Members of the lead PA with the Impact profiles submit permission upload the package's load shapes from the template on its page. Each series is checked in four stages: the file, its headers, each 8,760, and its match with the package's permutations.
  • Then generate the impact profiles from the accepted upload. Upload history has every upload's QC summary, and eTRM sync history lists any package left out and why, so its lead PA can fix it in eTRM.
