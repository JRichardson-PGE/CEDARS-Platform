Filing specifications

{% page_help "specifications/index" %}

What each kind of filing must contain: its tables, the fields of each table, which are required, each field's type and value list, and the rules and built-in checks every record is checked against. The CPUC publishes each specification in named versions that never change once published, and each filing set (a claim year, a budget filing, a year of monthly reports) is set up with one: its uploads and corrections use that version, whenever they are made. Several versions can be in use at once.
