Keep the register

{% page_help "releases/mandates_manage" %}

Draft an entry for each CPUC decision or resolution that changes CEDARS' data or calculations, link where CEDARS carries it, then publish it on the register. Only CPUC system administrators see drafts. A published entry is never deleted (one entered in error is withdrawn), and every later change needs a reason, which its public history shows. The register is public: enter only what the CPUC's public document says, and link the document on a ca.gov site.
