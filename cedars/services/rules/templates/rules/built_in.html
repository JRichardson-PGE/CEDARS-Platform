Built-in checks

{% page_help "rules/built_in" %}

Besides the published rule sets, each filing meets checks written in the platform's code. They need what a rule set cannot see: the program registry, the filing's cycle or month, the filing's other tables, earlier confirmations and eTRM. They are listed here to read; they change only with a release of the platform, which its release notes announce. A filing runs them as its filing specification version lists them: a check marked "a version may leave it out" runs only when the version lists it, with the severity the version gives it; every other check always runs.
