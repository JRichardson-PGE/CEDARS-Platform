CEDARS is built to meet WCAG 2.2 Level AA, as California requires of state agency sites. Every page is tested in the light and dark color schemes.

Key points

  • Everything works with a keyboard; Skip to content is the first stop, and the focus is always shown.
  • Status is given in words, never by color alone, and every chart has a table of the same numbers.
  • Pages reflow at 320 pixels wide and 200% zoom, and work without JavaScript.
  • Workbooks CEDARS makes are screen-reader friendly. Files you upload are checked, and you are told how to fix any problem.

Learn more

  • The tour on one page.
  • Making an accessible file: in Word or PowerPoint, export to PDF with document structure tags on; in Excel, use Review, Check Accessibility.
  • Found a barrier? See getting support: a barrier is a defect, and we fix it.
