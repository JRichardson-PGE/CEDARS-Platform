A new program gets a PrgID, kept for good and never reused, and a first version from the day it starts. Later changes start new versions from the program's page. Under each field is how to fill it in; Program fields (opens in a new tab) gives every field's definition and valid values.

A PA's ID for a statewide program, made of the PA's code and the statewide PrgID (for example PGE_SW_FS), follows that statewide program from the start: its attributes are copied from the statewide program, and the ones entered here are not used.
