Engine releases

{% page_help "calculations/engines" %}

The ReCET releases runs can use, the calculations each offers (ReCET's own and CET replicas) and the ACCs each has. A job asks for exactly one release, and the worker refuses any other, so a run's results always name the release that produced them. Filings (budgets, claims and monthly reports) are priced on the default release, so it needs the ACC of every filing still to come.

To move to a new release, add it below and make it the default; the release it replaces can be retired in the same step. A retired release stays on this list and its runs keep naming it.
